# 기획 문서

이 폴더는 "바이브코딩 가이드"가 무엇이고 어디까지 만들 것인지를 적어둔 곳이다.
코드를 읽으면 알 수 있는 것(파일 구조, 함수 이름)은 여기 쓰지 않는다.
**코드에 남지 않는 것 — 왜 그렇게 정했는지, 무엇을 일부러 뺐는지, 다음에 뭘 할지 —만 쓴다.**

## 이 문서들을 유지하는 규칙

1. **결정은 [06-결정-로그.md](06-결정-로그.md)에 append 한다.** 지난 항목을 고치지 않는다.
   생각이 바뀌면 새 항목을 쓰고 옛 항목에 "→ D-00N으로 대체됨"만 붙인다.
   나중에 "왜 Firebase가 아니지?"를 다시 논쟁하지 않기 위한 장치다.
2. **범위가 늘어나면 [02-기능범위.md](02-기능범위.md)의 표를 먼저 고친다.** 코드가 먼저 늘어나는 걸 막는다.
3. **스키마를 바꾸면 [04-데이터모델.md](04-데이터모델.md)와 `supabase/schema.sql`을 같이 고친다.** 둘이 어긋나면 SQL 파일이 정답이다.
4. **AI 기능을 추가하면 [08-AI기능.md](08-AI기능.md)의 표에 `maxTokens`와 함께 한 줄 추가한다.** 요금이 나가는 기능이라 목록이 흩어지면 관리가 안 된다.
5. AI 코딩 도구에게 작업을 시킬 때는 관련 문서를 통째로 붙여넣는다. 이 폴더는 그 용도로 쓰라고 만든 것이다.
