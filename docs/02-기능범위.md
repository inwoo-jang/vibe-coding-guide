## v1 — 친구 3명에게 링크를 보낼 수 있는 상태

### F1. 커리큘럼 열람 ✅

8단계 챕터를 순서대로 읽는다.

- 완료 조건: 모든 챕터에 (1) 요약 (2) 본문 (3) 프롬프트 1개 이상이 있고, 이전/다음 이동이 된다
- 관련: `src/data/chapters.js`, `/learn`, `/learn/:chapterId`

### F2. 단계별 프롬프트 + 복사 ✅

각 챕터 안에 그 단계에서 쓸 프롬프트가 있고, 한 번에 복사된다.

- 완료 조건: 복사 버튼이 동작하고, 복사됨 피드백이 보인다. `/prompts`에서 전체 검색이 된다
- 클립보드 권한이 없는 환경에서는 조용히 실패하고 텍스트는 화면에 그대로 남는다 (선택 복사 가능)

### F3. 프로젝트 단위 진도 ✅

**진도는 챕터가 아니라 프로젝트에 매달린다.** 사용자가 "만들고 싶은 것"을 하나
등록하고, 그 프로젝트를 기획부터 배포까지 8단계로 끌고 간다.

- 완료 조건: 프로젝트를 만들고 → 챕터를 체크하면 → 상단 %, 커리큘럼, 프로젝트
  대시보드가 새로고침 없이 같이 갱신된다. 프로젝트를 두 개 만들면 각각 0%부터다
- 프로젝트 없이도 콘텐츠는 전부 읽힌다. 프로젝트는 **기록할 때만** 필요하다
- 현재 저장소: `localStorage` — F5로 서버 저장으로 교체
- 옛 버전(`vcg.progress.v1`)의 기록은 첫 프로젝트로 자동 이관된다

**왜 이렇게 바꿨나:** 챕터별 체크만 있으면 "읽었다"는 기록이 된다. 이 가이드의
목적은 읽는 게 아니라 **한 사이클을 실제로 도는 것**이다. → [06](06-결정-로그.md) D-010

### F4. 용어 사전 ✅

AI가 자주 쓰는데 아무도 설명 안 해주는 단어를 검색한다.

- 완료 조건: 검색이 되고, 각 항목이 한 줄로 이해된다

### F5. 로그인 + 서버 진도 저장 📋

- 완료 조건: 이메일로 로그인하고, **다른 기기에서 열어도 진도가 그대로**다
- 방식: Supabase Auth **매직 링크(이메일 링크)**. 비밀번호를 만들지 않는다 — 대상이 초보라 비밀번호 분실 대응 비용이 더 크다
- 소셜 로그인은 v1에서 안 한다 (OAuth 앱 등록이 친구 3명 대비 과한 작업)
- 로그인하지 않아도 사이트는 전부 읽을 수 있어야 한다. **로그인은 진도 저장에만 필요하다**

### F6. 관리자 화면 + 접근 제어 🚧

누가 어디까지 왔는지 본다. 친구에게 "몇 번째 챕터에서 멈췄어?"라고 물어보려고 만든다.

- 완료 조건: `profiles.is_admin = true`인 사람만 `/admin`을 열 수 있다. 아닌 사람은 화면 자체를 못 본다
- **화면 숨김만으로는 안 된다.** DB의 RLS로도 막혀 있어야 한다 → [04-데이터모델.md](04-데이터모델.md)
- 현재: 화면 골격만 있고 누구나 열 수 있음

### F7. 배포 📋

- 완료 조건: Vercel에 올라가 있고, 친구에게 보낼 수 있는 주소가 있다. 환경변수가 배포 환경에 들어가 있다

### F7-1. 반응형 + 홈 화면에 추가(PWA) ✅

**커리큘럼은 하나의 트랙(반응형 웹)으로 간다.** 웹/모바일웹/앱으로 나누지 않는다 → D-015

- 사이트 자체가 반응형이다 (`src/index.css` 의 `@media (max-width: 640px)`)
- 사이트 자체가 홈 화면에 추가된다 (`public/manifest.webmanifest`, `index.html`)
- 완료 조건: **폰에서 이 사이트를 열어 홈 화면에 추가하면 주소창 없이 전체화면으로 뜬다**
- 콘텐츠 쪽 완료 조건: 설계 챕터에 "반응형", 빌드 챕터에 "폰에서 열어보기",
  배포 챕터에 "홈 화면에 추가" + "진짜 앱이 필요한 순간" 절이 있다
- 서비스워커·오프라인 지원은 **하지 않는다.** 캐시 무효화 문제가 초보에게 너무 어렵고,
  홈 화면 추가에는 필요 없다

### F8. AI 기능 ✅

내 프로젝트 정보를 아는 AI가 네 곳에서 돕는다. 상세: [08-AI기능.md](08-AI기능.md)

| 기능 | 어디서 |
|---|---|
| 아이디어 → PRD 뽑기 | 새 프로젝트 만들기 |
| 프롬프트를 내 프로젝트에 맞추기 | 모든 프롬프트 카드 |
| 이 단계 제대로 했는지 점검표 | 각 챕터 하단 |
| 모르는 용어 물어보기 | 용어 사전 |

- 제공자: **OpenAI** (`gpt-4o-mini` 기본)
- 완료 조건: 키가 있으면 네 기능이 동작하고, **키가 없으면 조용히 꺼진 채 사이트의
  나머지는 정상 동작한다**
- **키는 브라우저에 절대 나가지 않는다.** 서버리스 함수(`api/ai.js`)만 키를 안다
- 요금 방어 장치(자동 호출 금지·캐시·상한·빈도 제한)가 완료 조건에 포함된다.
  장치 없이 기능만 있으면 미완성으로 본다

### F9. 키 유출 방지 자동 검사 ✅

`npm run build` 가 항상 `scripts/check-env.mjs` 를 먼저 돌린다. 비밀 키에 `VITE_`
접두사가 붙었거나 소스에 키 모양 문자열이 있으면 **빌드를 중단한다.**

- 완료 조건: 일부러 위반했을 때 빌드가 실패한다 (`VITE_OPENAI_API_KEY=sk-test npm run build`)
- 이 사이트가 보안 챕터에서 가르치는 걸 스스로 지키는 장치다 → [09](09-보안-키관리.md)

|---|---|---|---|

| AI 응답 스트리밍 | ❌ | 코드가 복잡해지고 얻는 게 "글자가 하나씩 나오는 느낌"뿐이다 | 사실상 안 함 |

| 챕터 콘텐츠 CMS (DB에서 관리) | ⏸ | 지금은 `chapters.js` 한 파일 수정이 제일 빠르다. 객체 모양을 그대로 스키마로 쓸 수 있게 짜뒀다 | 코드를 못 만지는 사람이 글을 쓸 때 |
| 실습 체크리스트 (챕터 안 세부 항목 체크) | ⏸ | 진도 단위를 챕터로 잡았다. 세분화하면 스키마가 바뀐다 | 완주율이 낮고 원인이 챕터가 길어서일 때 |
| 댓글 / 커뮤니티 | ❌ | 관리 비용(스팸, 신고)이 콘텐츠 가치를 넘는다 | 사실상 안 함 |

| 결제 / 유료화 | ❌ | 친구에게 보낼 링크다 | 안 함 |
| 영상 | ❌ | 도구 UI가 바뀔 때마다 다시 찍어야 한다. 글은 고치면 된다 | 안 함 |
| 모바일 앱 | ❌ | 반응형 웹으로 충분하다 | 안 함 |

## 범위 밖 판정 기준

새 아이디어가 떠올랐을 때 아래 셋 중 하나라도 "아니오"면 v1에 넣지 않는다.

1. **친구 3명이 배포까지 가는 데 직접 도움이 되나?**
2. **이걸 빼면 가이드가 거짓말이 되나?** (예: 보안을 가르치는데 이 사이트가 안 지키면 거짓말이다 → 넣는다)
3. **한 번 앉아서 끝낼 수 있나?** 아니면 쪼개서 하나만 v1에 넣는다

AI 기능이라면 하나 더 묻는다.

4. **요금이 얼마나 나가나?** 상한(`maxTokens`)을 정할 수 없거나, 사용자가 모르는 사이
   반복 호출될 수 있는 기능은 넣지 않는다. → [08-AI기능.md](08-AI기능.md)
