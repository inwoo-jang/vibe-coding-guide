# AI 기능

작성 2026-08-03 · 제공자: **OpenAI** · 상태: 구현됨 (`.env.local` 에 키가 있어야 켜짐)

## 한눈에

| | |
|---|---|
| 어디서 호출되나 | `api/ai.js` — **서버**. 브라우저는 절대 OpenAI를 직접 부르지 않는다 |
| 브라우저 쪽 통로 | `src/lib/ai.js` 하나. 화면은 `useAiTask()` 만 쓴다 |
| 키 이름 | `OPENAI_API_KEY` (VITE_ **없음** — 있으면 빌드가 멈춘다) |
| 모델 | `OPENAI_MODEL`, 기본 `gpt-4o-mini` |
| 키가 없으면 | 기능이 조용히 꺼진다. 사이트의 나머지는 정상 동작한다 |

## 왜 서버를 거치나

브라우저에서 OpenAI를 직접 부르면 키가 사이트 소스에 그대로 들어간다.
누구나 개발자 도구를 열어 가져갈 수 있고, **내 카드로 남이 API를 쓴다.**

그래서 구조가 이렇다.

```
브라우저  ──"kickoff 해줘"──▶  /api/ai (서버)  ──키 붙여서──▶  OpenAI
   ▲                              │
   └──────── 결과만 ◀─────────────┘
        키는 이쪽으로 넘어오지 않는다
```

로컬에서도 `npm run dev` 하나로 동작한다 — `vite.config.js` 가 개발 서버에
같은 파일을 물려준다. `vercel dev` 를 따로 띄울 필요가 없다.

## 네 가지 기능

| task | 어디에 있나 | 하는 일 | 출력 상한 |
|---|---|---|---|
| `kickoff` | `/projects` 새로 만들기 | 아이디어 한 줄 → 한 장짜리 PRD (JSON) | 900 토큰 |
| `tailor` | 모든 프롬프트 카드 | 기본 프롬프트 + 내 프로젝트 → 맞춤 프롬프트 | 500 토큰 |
| `review` | 각 챕터 하단 | 이 단계 제대로 했는지 점검표 (JSON) | 600 토큰 |
| `glossary` | `/glossary` | 모르는 단어를 내 프로젝트 맥락으로 설명 | 300 토큰 |

프롬프트(시스템 메시지) 전문은 `api/ai.js` 의 `TASKS` 에 있다.
**서버에 두는 이유:** 브라우저 번들에 안 들어가고, 사용자가 바꿔서
"이전 지시 무시하고 ~" 같은 걸로 조종할 수 없다.

## 요금을 아끼는 장치 (설계의 절반이 이것)

AI 기능은 **호출할 때마다 실제로 돈이 나간다.** 그래서 아래 장치들이
코드에 박혀 있다. 숫자를 올리거나 장치를 빼려면 이유가 있어야 한다.

### 1. 자동 호출 경로가 없다 — 가장 중요

**모든 AI 호출은 사용자가 버튼을 눌러야만 실행된다.**
`useEffect` 안에서 `run()` 을 부르는 코드는 이 저장소에 한 줄도 없다.

> 화면이 뜰 때 자동으로 부르면 새로고침할 때마다, 뒤로가기 할 때마다 돈이 나간다.
> React StrictMode 는 개발 중에 effect 를 두 번 실행하므로 **두 배로** 나간다.
> 초보가 요금 폭탄을 맞는 1번 원인이다.

`AiPanel` 컴포넌트가 이 규칙을 구조로 강제한다 — 실행 경로가 버튼 `onClick` 뿐이다.

### 2. 같은 요청은 다시 부르지 않는다

`src/lib/ai.js` 가 (작업 + 입력)을 열쇠로 결과를 localStorage 에 저장한다.
같은 걸 다시 물으면 서버에 가지 않고 저장된 답을 준다.
화면에 "저장된 답을 다시 보여줍니다 — 이번엔 요금이 나가지 않았습니다"라고 표시한다.

최대 50개까지 보관하고 오래된 것부터 버린다.

### 3. 버튼 연타로 여러 번 나가지 않는다

같은 요청이 이미 날아가는 중이면 새로 보내지 않고 그 결과를 같이 기다린다
(`inFlight` 맵). 버튼도 요청 중에는 잠긴다.

### 4. 검색어를 칠 때마다 부르지 않는다

용어 사전에서 검색과 AI 질문을 **분리**했다. 타이핑에 반응해서 호출하면
글자 하나마다 요금이 나간다. AI는 버튼을 눌러야만 실행된다.

### 5. 입력과 출력 모두 상한이 있다

- 입력: 4000자에서 자른다 (`MAX_INPUT`). 입력도 과금 대상이다
- 출력: 작업마다 `maxTokens` 를 따로 정해뒀다 (위 표). 넉넉하게 잡으면 그만큼 돈이다
- 프로젝트 정보는 PRD 전체가 아니라 **필요한 줄만** 추려서 보낸다 (`projectContext()`)

### 6. 호출 빈도 제한

같은 사람이 **1분에 10번** 넘게 부르면 서버가 429로 거절한다 (`api/ai.js`).
실수로 만든 반복문이나 새로고침 연타에서 최악의 경우를 막는 장치다.

### 7. 쓴 만큼이 화면에 보인다

`/projects` 아래와 `/admin` 에 호출 횟수와 토큰 사용량이 표시된다.
캐시로 아낀 호출은 세지 않는다. **안 보이면 관리도 안 된다.**

## 새 AI 기능을 추가할 때 (체크리스트)

- [ ] `api/ai.js` 의 `TASKS` 에 항목을 추가한다 (시스템 프롬프트는 여기에)
- [ ] **`maxTokens` 를 반드시 정한다.** 이 숫자가 요금 상한이다
- [ ] 화면에서는 `useAiTask('내작업')` 을 쓰고 `AiPanel` 로 감싼다
- [ ] `run()` 을 **버튼 onClick 에만** 연결한다. `useEffect` 금지
- [ ] 보내는 입력이 필요 이상으로 길지 않은지 확인한다
- [ ] 이 표에 한 줄 추가한다

## 하지 않는 것

- **스트리밍** — 코드가 복잡해지고 얻는 게 "글자가 하나씩 나오는 느낌"뿐이다
- **대화 이어가기** — 매 턴마다 앞의 대화 전체를 다시 보낸다. 길어질수록 요금이 급증한다.
  지금 네 기능은 전부 한 번 물어보고 끝나는 형태다
- **사용자가 올린 파일 통째로 보내기** — PDF 한 개가 수만 토큰이다. 필요하면
  필요한 부분만 뽑아 보내야 한다
- **서버에 사용 로그 저장** — 지금은 브라우저에만 센다 → [05-이벤트-로그.md](05-이벤트-로그.md)

## 제공자를 바꾸려면

`api/ai.js` 한 파일만 고치면 된다 (`ENDPOINT`, 인증 헤더, 응답에서 텍스트 꺼내는 부분).
브라우저 쪽 코드와 화면은 하나도 안 바뀐다 — `lib/ai.js` 뒤에 숨겨져 있기 때문이다.
